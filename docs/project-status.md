# Project status and remaining completion evidence

<!-- markdownlint-disable MD013 -->

The original manifesto describes an owner-controlled economic intelligence node with planning, specialists, a sentinel, an evidence ledger and autonomous evolution. This repository now implements a connected, bounded version of each pillar for $AGIALPHA. General intelligence, self-improving enterprises, global marketplaces and reliably profitable operation remain broader ambitions. The owner explicitly separated this project from AGI Jobs.

| Area | Implemented through v3.2 | Evidence still needed |
| --- | --- | --- |
| Intelligence | Three verifiable work families, exact integer reconciliation and finite allocation search, explicit data rules, computed-fact model briefs, general model drafts and conservative outcome learning | Broad task benchmarks, reliable forecasting, superiority over alternatives and independent assessment of output usefulness |
| Specialist coordination | Signed discovery/requests/results, five capabilities, persistent budget reservations, separate processes, replay and failure controls | Real independent operators, service economics and any future automatic peer-payment marketplace |
| Useful work | Signed invoice/allocation/data-quality deliverables and JSON/CSV verification; reviewed changes with health/rollback; actual CPU-measurement demonstration | Representative production workloads and buyer acceptance; measured total economic value rather than illustrative CPU pricing |
| Learning | Comparable observed paired outcomes including rejections, full declared overhead, quality/time checks and exclusion of duplicate/overlapping/model-based records | Truthful, representative observations and causal attribution; signatures do not establish those facts |
| Identity and token | ENS checks, prefunded canonical-token escrow, exact-once transaction recovery, capped staking and fresh read-only claim auditing | Owner mainnet identity, actual deployed contracts/funding and live payments |
| Operation and recovery | CLI/interface and result downloads, reviewer-time admission, bounded execution, encrypted recovery and platform service configuration | Sustained operation, recovery and review capacity on the intended machines |
| Assurance | Scope-bound, expiring external assessment signatures and an enforceable evidence gate | Actual security, recovery, operations and reviewer-independence assessments by the named assessors |

The release can be installed and exercised without pretending those external conditions exist. Its evidence separates actual file/HTTP/model/CPU execution, controlled reviewer roles, generated inputs, modeled dollar amounts and local EVM payments. The software intentionally reports incomplete qualification when required evidence is absent.

Open project outcomes cannot be closed by another version number or a “10/10” label. See [qualification procedures](alpha-qualification.md), [release evidence](../evidence/v3.2.0/validation.md), and [the recovered original assessment](alpha-assessment.md).

The verified-work path constrains factual output to deterministic computations and permits models to prioritize those facts. It does not establish broad autonomous reasoning, causal prediction, general computer use or buyer demand. The exact allocator considers at most 16 supplied candidates. General research specialists can still make semantic errors and require independent review. These limits remain explicit acceptance boundaries.
